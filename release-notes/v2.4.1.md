# vMCP v2.4.1

## Local tools

Teams can serve text and Markdown through virtual MCP servers directly from VMCP. In **Upstreams → Add upstream**, choose **Local tools** and add a tool with its own description, parameters and response. Use a fixed response or a Go template with conditionals and loops. Inputs support strings, booleans and arrays of strings.

In **Try draft**, supply sample arguments and run the preview before applying the tool and saving its source. Then select the saved tool in the virtual MCP editor. Existing sharing, aliases and Agent guidance references apply. Continue to author local prompts and resources in **Agent guidance**. [PR #139](https://github.com/bishoku/vmcp/pull/139)

## Upgrade from v2.4.0

Helm chart 2.4.1 targets application v2.4.1. Apply database migration 48 through the usual migration step and upgrade the control plane, data planes and web UI before creating local sources. The migration adds storage for local definitions and preserves existing MCP and REST source configuration.
