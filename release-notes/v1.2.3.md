# Omni agent guidance and banking demo playground

vMCP v1.2.3 adds English Omni usage guidance and expands the optional quickstart
playground. No database migrations or breaking API changes are introduced.
Chart and OpenAPI versions are 1.2.3.

- Omni initialization instructions and all four tool descriptions recommend
  choosing a virtual server before discovering its tools, then reading the current
  schema before invocation. Global discovery remains supported.
- A versioned English Markdown guide is exposed through MCP resources at
  `omni://guides/discovery-workflow/v1`, with existing runtime authorization and
  revocation checks. No prompts or additional callable tools are introduced.
- Quickstart `--mock` creates a synthetic Meridian Bank playground with 30 teams,
  40 projects, 20 REST upstreams and 40 virtual servers, including cross-team
  approval scenarios. Optional `--keycloak` adds group-based SSO users and runtime
  identity bindings; `--omni` publishes newly created demo servers for discovery.
- The new `deploy/helm/vmcp/demo.sh` helper lists users, teams, projects, servers and
  upstreams, and explicitly retrieves locally stored demo credentials or tokens.
- Reruns preserve existing records, runtime keys, grant decisions, passwords and
  memberships. Older demo fixtures remain alongside newly created banking fixtures.

The playground contains synthetic data and is intended for trial environments.
Embedding and reranking endpoints remain optional. Deploy the matching Omni image
to receive the embedded guide; no new configuration is required for guidance.

See the [Omni guide](https://github.com/bishoku/vmcp/blob/v1.2.3/docs/Omni-MCP.md)
and [quickstart documentation](https://github.com/bishoku/vmcp/blob/v1.2.3/docs/HELM_QUICKSTART.md).
