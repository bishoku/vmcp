# Audit operation flow inspector

vMCP v0.1.3 improves audit investigations by grouping explicitly linked upstream calls under their parent tool operation and presenting the flow in a wide detail modal.

## Highlights

- Show a tool call and its linked upstream operations as one Operations row. Raw events remain individually accessible. Shared request or trace IDs alone do not merge unrelated operations.
- Use the parent outcome and duration for the operation summary. Missing parent or lifecycle outcomes remain explicitly incomplete, rather than implying success or failure.
- Open audit details in a wide desktop modal and a full-screen mobile view. Select a logical step to inspect its request and response side by side, and expand technical context to inspect every stored record.
- Preserve administrator-only, on-demand payload retrieval and distinguish disabled capture, redaction, expiry, and retrieval errors.
- Add regression coverage and documentation for nested REST request bodies, arrays, numeric precision, validation, and virtual MCP order calls. REST payload mapping behavior is unchanged.

## Upgrade notes

- No new database migration, API contract, or configuration change is introduced relative to v0.1.2.
- Update the web UI to receive the new audit investigation experience. Existing payload capture, masking, and retention policies continue to apply.
- Filters and pagination can still omit related records. Load additional records or open the operation correlation link when investigating an incomplete selection.
- Upgrades from versions earlier than v0.1.2 must also follow the v0.1.2 migration and audit-role grant instructions.
