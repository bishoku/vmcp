# vMCP v2.3.3

- REST upstreams can serve JSON and plain text from separate operations on the same connection. Choose **Plain text** under **Request & tool → Response format** to request UTF-8 text and return it as a single string. Diffs and logs retain their line endings. Existing operations default to JSON. [Issue #130](https://github.com/bishoku/vmcp/issues/130)
- Audit and PII masking rule editors can preview how a regular expression matches sample input before saving the rule. [PR #127](https://github.com/bishoku/vmcp/pull/127)

Upgrade the control plane, web and data-plane replicas before enabling text operations. Helm chart 2.3.3 and the versioned Kustomize bundle ship with the release. No database migration is required.
