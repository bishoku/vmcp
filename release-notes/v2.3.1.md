# vMCP v2.3.1

## Helm quickstart

Preview a fresh installation with `deploy/helm/vmcp/quickstart.sh --version v2.3.1 --dry-run`. The quickstart renders both Helm releases, placeholder credentials and bootstrap resources without contacting Kubernetes. Use `--output-dir` to choose a new directory. For a fully offline preview, supply a local chart and matching image manifest with `--chart` and `--images-file`. The generated README explains which steps need a live cluster. Preview credentials are placeholders and the output is for inspection. [Quickstart change](https://github.com/bishoku/vmcp/pull/85)

## Management console

- **Settings → Gateway version** reports the release tag embedded in the running control plane. Official v2.3.1 images and standalone binaries report `v2.3.1`; local builds report `dev`. [Gateway version fix](https://github.com/bishoku/vmcp/pull/113)
- Team, project and tool-access dialogs use the standard form cards. Dialog content stays opaque throughout the opening animation. The Audit conversations page groups its filters in a card and keeps its header actions at the standard desktop and mobile heights. [UI fixes](https://github.com/bishoku/vmcp/pull/115)

## Release verification

A release tag can reuse successful main push CI checks for its exact commit. Missing or incomplete evidence triggers full CI. For evidence at least 24 hours old, publication refreshes the dependency vulnerability checks. Each release still scans its AMD64 and ARM64 image digests and verifies image signatures. [Release CI change](https://github.com/bishoku/vmcp/pull/118)

## Upgrade

Use Helm chart 2.3.1 with the matching image overlay or the versioned Kustomize bundle. The database schema remains at migration 47.
