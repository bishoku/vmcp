# vMCP v2.3.2

REST upstream tools can now accept repository-relative paths at the end of an operation URL. In the operation editor, enable **repository-relative path** for the final string path parameter. Clear **required** to let agents omit the argument when browsing the repository root. A Bitbucket Data Center browse tool can then navigate from the root to `src/main` and into a returned child directory with one tool.

Relative paths are validated and escaped segment by segment. A leading slash produces a corrective hint. Existing REST operations keep their single-segment behavior. Upgrade all data-plane replicas before enabling the new parameter mode. No database migration is required. [Issue #128](https://github.com/bishoku/vmcp/issues/128)
