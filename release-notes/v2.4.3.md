# vMCP v2.4.3

## OTLP/gRPC for gateway telemetry

Control-plane, data-plane and omni-mcp can send logs, metrics and traces to a Collector over gRPC. Set the following variables on each service, using your Collector's gRPC receiver address.

```sh
OTEL_EXPORTER_OTLP_PROTOCOL=grpc
OTEL_EXPORTER_OTLP_ENDPOINT=https://collector.example:4317
```

HTTP/protobuf remains the default when the protocol is unset. Signal-specific protocol and endpoint settings take precedence over the common settings. [Operator guide](https://github.com/bishoku/vmcp/blob/v2.4.3/docs/OBSERVABILITY.md#opentelemetry) · [PR #147](https://github.com/bishoku/vmcp/pull/147)

## Upgrade from v2.4.2

Helm chart 2.4.3 targets application v2.4.3. The database schema remains at migration 48. Existing HTTP/protobuf and Prometheus-only deployments can upgrade with their current settings.
