# vMCP v2.2.3

## Kubernetes deployment

- Install vMCP with kubectl or Argo CD using the new `vmcp-kustomize-v2.2.3.tar.gz` release asset. The production bundle uses the published image digests and includes separate prerequisites, a version-specific migration Job, and application resources. Argo CD sync waves wait for migration before updating workloads.
- Follow the [Kustomize installation guide](https://github.com/bishoku/vmcp/wiki/Kustomize-Installation) to verify the checksum, configure external PostgreSQL and Redis, supply Secrets, and customize ingress and network policies.

## Management console

- The control plane validates REST operation and JSON Schema drafts for the editors under the existing Content Security Policy. Review validation errors while editing and before saving changes.

## Upgrade and rollback

Helm users can upgrade with chart 2.2.3 and the matching image overlay. The database schema remains at migration 47. Existing Helm installations can continue using Helm. For Kustomize upgrades, back up PostgreSQL and wait for the new Job before updating the application. Rolling back workloads does not revert database migrations.
