First optimization package — local synthetic measurements, 2026-10-16
Go 1.27.2; Darwin arm64; Apple M5 Max; local Docker PostgreSQL 17.
Three repetitions. Config/audit/preparation: 300ms. Before/after metrics and calls: 1s.
No race instrumentation. These are not production or multi-node capacity claims.

Summary (median of three):
  64-event audit transaction: sequential 20.007 ms; pipeline 5.578 ms.
  10k-resource exact lookup: linear 23.767 us; indexed 16.50 ns.
  Masked 200-tool page: fallback 1.113 ms / ~969 KB; prepared 2.615 us / 32 KB.
  2k-series continuous-scrape contention: before 160.966 us/op; after 470.7 ns/op.
  Calls, larger inventory: p95 before 10.97 ms; after 7.931 ms.
  Calls, larger inventory: p99 before 12.08 ms; after 9.077 ms.
  SQL statements remain ~4.5/call; improvement is batching/wire/CPU cost.
  Metadata prep (10k tools + 10k resources): ~80 ms, ~72 MB allocated, ~11.3 MB retained.

Audit pipelining allocates more: ~167 KB versus ~40 KB per 64-event batch.
Catalog metadata cache-hit nanoseconds exclude HTTP serialization; do not interpret as API latency.
